# Daniel Corbier

## Software Architect | Founder of uCalc Software | [www.ucalc.com](https://www.ucalc.com/)

I'm **Daniel Corbier**, a software architect and founder of uCalc Software.

I build software development tools focused on parsing, expression evaluation, intelligent text transformation, and innovative search.

Through uCalc Software, I'm developing a cross-platform SDK that brings together high-performance mathematical expression parsing and token-aware structural text transformation.  I'm also building a platform for constructing programming languages.

The uCalc SDK focuses on:

* **Math Expression Parsing**: Fast parsing and evaluation of mathematical expressions.
* **Token-Aware Text Transformation**: Structural text and code transformation beyond traditional regular expressions.
* **Developer Tools**: Libraries and technologies for building parsers, domain-specific languages (DSLs), and advanced text-processing applications.
* **Cross-Platform Development**: Support for Windows, macOS, Linux, and more.
